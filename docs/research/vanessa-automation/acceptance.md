## Сравнение скилла

Попеременные проверки одинакового вопроса в свежих контекстах сохранили PASS
по маршрутизации, формату ответа и публичным источникам. В обоих вариантах —
по два поиска с limit=5. Медиана полного времени ответа: прежний скилл 43,998 с,
обновлённый 46,848 с (+2,850 с). Ускорение не подтверждено; строгий сравнительный
критерий «время не хуже» не выполнен. Эти значения включают генерацию ответа
и не измеряют отдельно задержку MCP. Сохранён исходный поисковый бюджет;
добавлена только маршрутизация Vanessa и правила источников. Подробности —
[skill-checks.json](skill-checks.json).
