# Проверка обновления библиотечных скиллов 2026-10-04

Обновлены все десять навыков из списка установки на публичной странице
`https://aichat.msgplaut.com/ai-library`: `lib-1c-cons`, `lib-1c-dev`,
`lib-1c-erp`, `lib-nifi`, `lib-pm2-it`, `lib-postgresql`, `lib-sap-cons`,
`lib-sap-dev`, `lib-sap-process-navigator`, `lib-sap-sf-odata`.
Версия пакетов — `1.0.0`; версия docs-mcp-server остаётся `3.2.1`.

## Изменение

Каждый навык проверяет новую версию после определения области и до поиска.
После установки новой версии агент полностью перечитывает инструкцию и нужные
справочные файлы. Проверка выполняется один раз на запрос. Общие инструкции и
Python updater собираются в автономные пакеты из одного источника.
Уточнение неоднозначного вопроса, выбор книг, языковая политика, бюджеты поиска,
источники и работа с исходными артефактами сохранены.

## Независимое исполнение инструкций

Одинаковый вопрос NiFi до и после изменения получил полное подтверждение,
включая особенности Stateless Engine. Оба варианта сделали один `find_version`
и один `search_docs(limit=5)`. Недоступный до публикации каталог обновления
оставил установленный навык работоспособным. Проверка пакета заняла 0,3 секунды.
Это одна сравнительная пара, а не оценка постоянной скорости внешнего MCP.

Общий вопрос про BPMN закупки получил один уточняющий вопрос без сетевых
вызовов, поиска или скачивания.

Отдельная временная установка `lib-1c-erp` обновилась с `0.9.0` до `1.0.0`
с публичного сайта. Независимый агент запустил updater один раз, полностью
перечитал новую инструкцию и нужные references, затем сделал один поиск
`onec_erp(limit=5)`. Ответ сохранил источники и установленный формат. Байты
обновлённых файлов дополнительно сравнены с выпущенным пакетом.

Сайт обновлён с сохранением предыдущих публичных файлов для восстановления.
Сырые ответы MCP, клиентские настройки подключения и секреты в отчёт не входят.
