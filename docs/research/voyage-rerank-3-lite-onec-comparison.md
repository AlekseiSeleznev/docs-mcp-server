# Сравнение Voyage rerank-2.5-lite и rerank-3-lite

Дата: 4 октября 2026 года.

## Решение

`rerank-3-lite` включена в рабочем поиске. На неизменном наборе из 40 запросов
она улучшает MRR и nDCG@5; рабочий MCP подтверждает полученное качество.

До изменения рабочая конфигурация содержала `enabled: false` и
`model: rerank-2.5-lite`. У worker отсутствовали включающие переменные
окружения. Наличие ключа Voyage само по себе не включало reranking.
Момент и причина отключения не установлены.

## Условия сравнения

- Корпус: `onec_erp_implementation@2026.8.8`, 82 страницы, 312 фрагментов.
- Набор запросов: SHA-256 `6e048569089ec05445f73a1d67975290bc7554357a691e7c0c8d053a802161c5`.
- Содержимое корпуса: SHA-256 `2fe2d189896720613015bcdf410c9e68498c490dbdc1788899d9d13769d82448`.
- Эмбеддинги: `openai:baai/bge-m3`, 1024 измерения.
- Кандидаты: 30; лимит результатов для метрик: 30; таймаут Voyage: 5000 мс.
- Два последовательных повтора с чередованием порядка моделей.
- Обе модели получают одинаковые кандидаты из общего кеша в памяти.
- Измеряется реальный Voyage API через штатный адаптер и сборку контекста.
- Корпус открыт только для чтения; его контрольная сумма до и после одинакова.

## Качество

Результаты качества одинаковы в обоих повторах.

| Метрика | rerank-2.5-lite | rerank-3-lite |
|---|---:|---:|
| MRR | 90.17% | 91.92% |
| nDCG@5 | 90.88% | 91.85% |
| Hit@1 | 82.50% | 87.50% |
| Recall@3 | 97.50% | 95.00% |
| Recall@5 | 97.50% | 97.50% |
| Recall@30 | 100.00% | 100.00% |

MRR растёт на 1,75 процентного пункта; nDCG@5 — на 0,98 пункта.
Правильный результат на первой позиции встречается в 35 запросах вместо 33.
По nDCG@5: 5 улучшений, 30 равенств, 5 ухудшений. Общий прирост определяется
величиной изменений, а не числом выигранных запросов.

Компромисс: Recall@3 снижается на 2,5 пункта. Это означает, что отдельный
релевантный материал может уйти за первые три результата. Recall@5 и Recall@30
сохраняются. Вывод ограничен этим корпусом; статистическая значимость и
улучшение других библиотек не установлены.

## Рабочее включение и проверка

В активный Compose добавлены только настройки worker:

```dotenv
DOCS_MCP_SEARCH_RERANKER_ENABLED=true
DOCS_MCP_SEARCH_RERANKER_MODEL=rerank-3-lite
DOCS_MCP_SEARCH_RERANKER_CANDIDATE_LIMIT=30
```

Общий конфигурационный файл остаётся с выключенным значением по умолчанию,
чтобы MCP и web, работающие как прокси, не требовали ключ Voyage. На worker
переменные окружения имеют приоритет над этим файлом.

Пересоздан только worker. Неизменный образ:
`ghcr.io/alekseiseleznev/docs-mcp-server@sha256:e8a1b2823fa30b2ef9bd3e4c0673fb596ecb0eebc9ad5986e26796d3c55bd79f`.
Предыдущий Compose сохранён рядом с активным файлом как
`docker-compose.before-rerank-3-lite-20261004.yml` с правами 0600.
Настройки эмбеддингов и том индекса сохранены.
