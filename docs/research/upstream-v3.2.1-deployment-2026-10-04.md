## Ошибки веб-интерфейса

Запросы состояния, истории и заданий из пользовательского скриншота повторно
проверены напрямую, через Apache и браузером. HTTP-запросы и пакетный запрос
вернули 200 без ошибок. Исходный `NetworkError` на момент проверки не повторился;
его точная причина по одному скриншоту не установлена.

Отдельно воспроизведён дефект WebSocket: приложение отвечало 101, Apache — 404.
В web virtual host добавлен `upgrade=websocket`; конфигурация проверена перед
reload. После изменения оба пути отвечают 101, браузер загружает интерфейс без
ошибок запросов. Репозиторный Apache-шаблон обновлён тем же изменением.
Все три внешних listener без авторизации возвращают 401.
Исходный и новый хеши конфигурации и точная обратная операция сохранены в
защищённом `proxy-change.json`; файл с credentials не копируется в отчёт.

Основание настройки: [официальный пример Apache для WebSocket](https://httpd.apache.org/docs/2.4/mod/mod_proxy.html#examples).
