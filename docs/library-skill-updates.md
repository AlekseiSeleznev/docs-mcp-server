# Обновление библиотечных скиллов

Все десять скиллов из списка установки на `/ai-library` получают версию пакета
в `metadata.version`. Эта версия независима от версии docs-mcp-server и версий
индексируемых книг. Первый выпуск с проверкой обновления — `1.0.0`.

Когда область вопроса определена, агент читает `references/skill-update.md` и
один раз запускает `scripts/update-skill.py`. Скрипт обращается к публичному
`skill-versions.json`, а ZIP скачивает только для более новой версии. До записи
он проверяет контрольные суммы архива, всех файлов и сведения о выпуске.
После успешной установки агент полностью перечитывает `SKILL.md` и нужные
справочные файлы, затем применяет их к исходному вопросу.

Существующий `agents/openai.yaml` сохраняется: настройки подключения принадлежат
клиенту. Локальные правки файлов из предыдущего выпуска блокируют автоматическую
замену. При обычной ошибке записи изменённые файлы восстанавливаются. Ошибка
сети или некорректный выпуск оставляют установленную версию доступной для поиска.
Скрипт использует Python 3 и стандартную библиотеку; для записи нужны права на
папку скилла. Клиент с доступом только на чтение проверяет каталог версий и
сообщает о новой версии для установки через интерфейс клиента.

Для выпуска новой версии:

1. Измените исходники соответствующего `skills/lib-*/` и увеличьте
   `metadata.version` в его `SKILL.md`.
2. Выполните `python3 scripts/build-library-skills.py`. Общие инструкции и
   updater берутся из `skills/lib-skill-creator/references/skill-update.md` и
   `scripts/update-library-skill.py`; копии внутри ZIP создаются автоматически.
3. Выполните проверки навыков, `npm run lint`, `npm run typecheck` и `npm test`.
   `test/library-skill-update-e2e.test.ts` проверяет обновление через настоящий
   HTTP-сервер и соответствие всех десяти ZIP исходникам и каталогу.
4. Опубликуйте десять ZIP из `skills/md/downloads/`, страницу
   `skills/md/library-skills.html` как `index.html` и каталог
   `skills/md/skill-versions.json`. Каталог публикуется после соответствующих
   архивов; сохраните предыдущие публичные файлы для восстановления.
5. Сравните доступные по HTTPS файлы с репозиторием и проверьте обновление в
   отдельной установленной копии. Сохраните обезличенный результат проверки.

Обновление пакета выполняется отдельно от поиска документации. Бюджеты MCP,
выбор книг, проверка версий, источники и получение артефактов остаются правилами
профильного скилла. Неоднозначный вопрос сначала уточняется без сетевых вызовов.
