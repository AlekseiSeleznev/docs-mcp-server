# Резервная копия `lib-*` до унификации

Создано: 2026-08-30 11:33:42 Europe/Moscow (`+03:00`).

Назначение: неизменяемый baseline всех библиотечных скилов перед переносом в
`docs-mcp-server`, ускорением поиска и заменой `lib-skill-creation` на
`lib-skill-creator`.

## Источники

- `docs-mcp-server`: `2d6d8b862c8c26d221800c902a85394d0a1d572d`
- `sap-library-mcp`: `79e2b4a7603fa66d2cc95258f06f17b045464ec8`
- `onec-library-mcp`: `3d80c267d7c256452b710afd150c152a0563bd84`

Архивы `*-skills.tar.gz` содержат полные исходные каталоги скилов из трёх
репозиториев и состояние активных установок Codex. Обычные установленные
каталоги скопированы полностью, символические ссылки сохранены как ссылки.
`catalogs/` содержит отдельные читаемые копии мастер-каталогов SAP и 1С. Состав
архивов и цели ссылок записаны в `inventory.json`.

`baseline/` предназначен для сырых и сводных результатов сравнительных тестов
старой версии. Ни один файл из этой резервной копии не является активной
установкой скила.

## Проверка

Из этого каталога выполните:

```bash
sha256sum -c SHA256SUMS
```

Все строки должны завершиться `OK`.

## Восстановление

Для выборочного восстановления распакуйте соответствующий `tar.gz` во
временный каталог и скопируйте нужный каталог
`sources/<репозиторий>/skills/<имя>` обратно в исходный `skills/`, затем
повторно выполните его валидацию.

Для восстановления установки Codex удалите только соответствующий известный
`~/.codex/skills/lib-*` и создайте ссылку на восстановленный репозиторный
каталог. Обычные каталоги из `installed/` можно вернуть целиком после проверки
`SHA256SUMS`.

Не восстанавливайте весь каталог поверх рабочей копии без проверки текущего
`git status`: на момент снимка в `docs-mcp-server` существовали посторонние
пользовательские удаления, которые в резервную копию скилов не входят.
