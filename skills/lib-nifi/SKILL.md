# Документация Apache NiFi 2

Подтверждать сведения через read-only MCP `lib-docs`. Выполнять поиск только в
библиотеке `nifi`.

## Границы источника

- Использовать документацию NiFi 2 из найденной версии библиотеки `nifi`.
- Принимать как первичные источники результаты с URL под
  `https://nifi.apache.org/components/` и `https://nifi.apache.org/nifi-docs/`.
- Для вопроса о NiFi 1 сообщать, что библиотека покрывает NiFi 2, и запрашивать
  отдельный источник только по явному указанию пользователя.

## Поиск

1. Вызвать `find_version` для библиотеки `nifi`: использовать указанную
   пользователем версию NiFi 2, а при отсутствии версии — ограничение `2.x`.
   Передавать найденную версию во все вызовы `search_docs`.
2. Сформулировать запрос терминами NiFi. Для конкретного компонента включить его
   точное имя и искомый аспект: свойства, relationships, scheduling, state,
   ограничения или пример настройки.
3. Вызвать `search_docs` с `library="nifi"`, найденной версией и `limit=5`.
   Проверить, подтверждает ли фрагмент запрошенный факт и существенные условия.
4. При неполном подтверждении уточнить запрос и повторить поиск не более двух
   раз. После трёх поисков завершить с результатом «подтверждение не найдено».
5. Вызвать `fetch_url` для URL из результата поиска, только когда фрагмент
   обрывает нужную таблицу, список свойств или условие. Считать шаг завершённым,
   когда каждый существенный вывод поддержан найденным фрагментом или полной
   страницей.

## Диагностика

При ошибке доступности или имени библиотеки вызвать `list_libraries` один раз и
проверить наличие `nifi`. Прямо сообщить, если MCP недоступен, версия не найдена
или библиотека ещё индексируется.

## Ответ

- Указывать найденную версию NiFi и давать ссылки на использованные страницы.
- Сохранять точные имена компонентов, свойств, relationships, допустимых
  значений и режимов выполнения.
- Для инструкции по настройке собирать все подтверждённые prerequisites,
  обязательные свойства, выходные relationships и эксплуатационные оговорки.
- Отделять собственный вывод от сведений, прямо подтверждённых документацией.
- Прямо сообщать «подтверждение не найдено», когда поиск не дал достаточного
  основания для ответа.
