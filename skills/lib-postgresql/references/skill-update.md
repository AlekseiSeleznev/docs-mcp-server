# Проверка обновления

Когда область запроса определена, один раз перед поиском проверь версию этого
скилла на https://aichat.msgplaut.com/ai-library. Эта проверка обновляет пакет
навыка; поиск документации затем выполняется через `lib-docs`.

В клиенте с Python 3 и записью в папку установленного скилла выполни:

`python3 <skill-dir>/scripts/update-skill.py`

`<skill-dir>` — папка именно прочитанного `SKILL.md`; разреши путь относительно
неё. Скрипт читает `skill-versions.json`, сравнивает `metadata.version`, проверяет
ZIP и все файлы по SHA-256 и сохраняет настройки `agents/openai.yaml`.

- `updated`: полностью перечитай установленный `SKILL.md` и нужные ему
  справочные файлы, затем заново примени правила к исходному вопросу.
- `current` или `local_newer`: продолжи установленной инструкцией.
- `unavailable` или `blocked`: сохрани установленную версию и кратко сообщи,
  почему обновление не выполнено; продолжи её обычный поиск. Содержательные
  факты по-прежнему подтверждай библиотечным MCP.

Сообщение о состоянии обновления давай коротко до поиска; итоговый ответ
оформляй по профильным правилам скилла.

Проверка завершена после одного результата; перечитывание обновлённого навыка
не запускает её повторно в том же запросе. Неоднозначный вопрос сначала уточни
по правилам выбора области; обновление выполняется после уточнения.

Если Python или запись в папку скилла недоступны, проверь каталог версий
доступным Web-инструментом. Для новой версии используй штатную установку
навыков клиента из `downloads/<имя-скилла>.zip`, затем перечитай инструкцию.
Если клиент предоставляет только чтение, сообщи о доступном обновлении и
продолжи установленной версией; не называй её обновлённой.
