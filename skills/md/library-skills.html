С чего начать

Подключите доступ к библиотекам, затем установите нужные скилы.

Внимание. Устанавливайте только те скилы, которыми планируете пользоваться. Лишние скилы занимают контекст ИИ и могут снижать точность выбора нужного инструмента.

Скилы библиотеки

Выберите скил, чтобы перейти к его библиотекам и материалам.

СкилКраткое описание
lib-1c-cons
Прикладная и методическая документация 1С для консультантов и пользователей.
lib-1c-dev
Документация по платформе, BSL, БСП, интеграциям и разработке 1С.
lib-sap-dev
Разработка SAP: ABAP, SAPUI5/Fiori, OData, IDoc, интеграция, SAP HANA и платформа данных.
lib-sap-cons
Прикладная документация SAP по финансам, логистике, HCM, аналитике, безопасности и внедрению.
lib-sap-process-navigator
Поиск процессов SAP Best Practices и получение исходных артефактов по явному запросу.
lib-sap-sf-odata
Документация по SAP SuccessFactors OData V2 API.
lib-nifi
Официальная документация Apache NiFi 2.
lib-postgresql
Официальная документация PostgreSQL 18.
lib-pm2-it
Методология PM² для управления IT-проектами и программами.

Как подключить MCP

Выберите способ подключения и используйте предоставленный токен.

Для Claude Desktop, Cowork и Claude в браузере

Библиотека доступна через Web-коннектор. Подключите его к своему аккаунту Claude.

  1. Откройте Settings → Connectors и найдите Web-коннектор библиотеки lib.
  2. Нажмите Connect. На странице Plaut AI Library введите предоставленный токен и нажмите Войти.
  3. После возвращения в Claude убедитесь, что коннектор подключён. В разделе Tool permissions для группы Read-only tools выберите Always allow, чтобы Claude мог искать материалы без отдельного подтверждения каждого вызова.

Для Codex, Cursor и других ИИ-агентов

Скопируйте этот промт и отправьте его вашему ИИ.

Подключи глобально для всех проектов MCP-сервер по адресу https://aichat.msgplaut.com/lib-docs/mcp и зарегистрируй его под точным именем lib-docs — это имя используют библиотечные скилы. Используй Bearer Token <ВСТАВЬТЕ ПРЕДОСТАВЛЕННЫЙ ТОКЕН>. Сохрани подключение в постоянной глобальной конфигурации текущего ИИ-клиента, а токен — в поддерживаемом им безопасном хранилище секретов или постоянной переменной окружения, чтобы MCP автоматически подключался после перезапуска. После настройки проверь подключение и доступность инструментов MCP.

Токен и помощь. Токен получите у Алексея Селезнева. В случае затруднений напишите ему в MS Teams: alexey.seleznev@msgplaut.com.

Как пользоваться

Явно укажите нужный скил, затем задайте вопрос обычным языком.

В Claude вызывайте скил через /имя-скила, в Codex — через $имя-скила. Это помогает ИИ сразу выбрать правильную область документации.

1.

Обычный вопрос

Назовите скил и сформулируйте вопрос без специальных команд поиска.

Claude/lib-sap-dev Чем отличаются STANDARD, SORTED и HASHED tables в ABAP? Codex$lib-sap-dev Чем отличаются STANDARD, SORTED и HASHED tables в ABAP?
2.

Продукт, модуль или тема

Укажите предметную область, чтобы сразу сузить поиск.

Claude/lib-sap-cons В SAP S/4HANA Finance как настраивается account determination? Codex$lib-sap-cons В SAP S/4HANA Finance как настраивается account determination?
3.

Конкретная библиотека

Техническое имя библиотеки можно взять из таблицы «Скилы и материалы».

Claude/lib-sap-dev Используй библиотеку sap_books_abap и объясни, как применять ABAP Unit. Codex$lib-sap-dev Используй библиотеку sap_books_abap и объясни, как применять ABAP Unit.
4.

Конкретная книга

Укажите название как в таблице — скил не будет подменять книгу похожей.

Claude/lib-sap-dev По книге «ABAP to the Future 4e» объясни рекомендации по современному ABAP. Codex$lib-sap-dev По книге «ABAP to the Future 4e» объясни рекомендации по современному ABAP.

Если вопрос неоднозначен, ИИ сначала попросит уточнить предметную область. Если поиск выполнен, ответ содержит подтверждённые источники и перечень использованных библиотек.

Получение исходников. Эта возможность доступна только для скилов и библиотек, которые её поддерживают. Например: для SAP Process Navigator в Claude начните запрос с /lib-sap-process-navigator, в Codex — с $lib-sap-process-navigator, затем укажите process ID или Process Card и явно назовите test script, BPMN-модель или другой исходный артефакт, который нужно скачать. Обычный информационный вопрос файлы не скачивает.
