# Документация SAP SuccessFactors OData V2

Подтверждать сведения через read-only MCP `lib-docs`. Выполнять поиск только в
библиотеке `sap-sf-odata`.

## Границы источника

- Применять навык, когда пользователь прямо указал `SAP SuccessFactors`,
  `SuccessFactor`, `SuccessFactors`, `SF OData` либо назвал сущность или операцию
  именно SuccessFactors API.
- Для вопроса только об `OData` или `SAP OData` без контекста SuccessFactors
  сначала определить продукт и выбрать соответствующий источник.
- Использовать SAP SuccessFactors API Reference Guide for OData V2 из найденной
  версии библиотеки `sap-sf-odata`.
- Принимать как первичные источники результаты под
  `https://help.sap.com/docs/successfactors-platform/sap-successfactors-api-reference-guide-odata-v2`.
- Сохранять различие между SuccessFactors OData V2 и другими версиями API. Для
  вопроса об OData V4, SAP Gateway, S/4HANA, ByDesign или другом SAP API
  запрашивать отдельный источник.

## Поиск

1. Если пользователь указал релиз, привести четырёхзначную метку SAP к версии
   индекса: например, `2605` преобразовать в `2605.0.0`. Вызвать `find_version`
   с полученной версией.
2. Сформулировать запрос терминами SAP. Для сущности или операции включить её
   точное имя и искомый аспект: свойства, permissions, payload, navigation,
   filtering, pagination, ограничения или ошибки.
3. Вызвать `search_docs` с `library="sap-sf-odata"`, найденной версией и
   `limit=5`.
4. Проверить, подтверждает ли найденный фрагмент запрошенный факт и существенные
   условия. При неполном подтверждении уточнить запрос и повторить поиск не
   более двух раз. После трёх поисков завершить с результатом «подтверждение не
   найдено».
5. Вызвать `fetch_url` для URL из результата поиска, только когда фрагмент
   обрывает нужную таблицу, пример payload или условие. Считать поиск
   завершённым, когда каждый существенный вывод поддержан найденным фрагментом
   или полной страницей.

## Диагностика

- При ошибке доступности или имени библиотеки вызвать `list_libraries` один раз
  и проверить наличие `sap-sf-odata`.
- Прямо сообщить, если MCP недоступен, версия не найдена или библиотека ещё
  индексируется.

## Ответ

- Указывать найденный релиз SAP и давать ссылки на использованные страницы.
- Сохранять точные имена сущностей, свойств, navigation properties, операций,
  HTTP-методов, параметров запроса, кодов ошибок и разрешений.
- Для примера запроса включать только подтверждённые endpoint, параметры и
  обязательные поля.
- Отделять собственный вывод от сведений, прямо подтверждённых документацией.
- Прямо сообщать «подтверждение не найдено», когда поиск не дал достаточного
  основания для ответа.
